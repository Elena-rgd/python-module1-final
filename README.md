## Назначение

Консольная программа сравнивает плановый и фактический выпуск изделий мастерской.
План составляет 100 изделий за смену, выработка за смену постоянная. Программа
считает общий план, общий факт, отклонение, процент выполнения и определяет статус
(«Недовыполнение», «План выполнен», «Перевыполнение»). Затем выводит таблицу
плана и факта нарастающим итогом по сменам.

## Используемые темы Python

- ввод данных и преобразование типов (`input`, `int`), типы `str`, `int`, `float`, `bool`;
- арифметические операторы, сравнения, составные операторы (`+=`);
- условия `if–elif–else` и логические операторы `and`, `not`;
- цикл `for` с `range()` (таблица по сменам);
- цикл `while` (проверка ввода и повтор расчёта);
- собственные функции с параметрами и `return`;
- f-строки и форматирование: выравнивание, ширина полей, `:02d`, `:.1%`.

## Константы и переменные

**Глобальные константы** (уровень модуля):

| Имя | Значение | Назначение |
|---|---|---|
| `PLAN_PER_SHIFT` | 100 | плановый выпуск за смену, изделий |
| `WIDTH` | 60 | ширина отчёта и заголовка |
| `LABEL_W` | 40 | ширина поля подписи |
| `VALUE_W` | 20 | ширина поля значения |
| `COL_W` | 20 | ширина столбца таблицы |

**Основные переменные главного сценария:** `running` (bool, продолжать ли работу),
`workshop` (название), `shifts` (число смен), `output` (выработка за смену),
`total_plan` и `total_fact` (общий план и факт).

**Локальные переменные функций:** `deviation`, `percent`, `status` в `print_report`;
`plan_sum`, `fact_sum`, `shift`, `shift_text` в `print_table`; `answer`, `question`
в `ask_repeat`.

## Функции

- `read_shifts()` запрашивает число смен от 1 до 10;
- `read_output()` запрашивает неотрицательную выработку;
- `get_status(fact, plan)` возвращает статус выполнения плана;
- `get_percent(fact, plan)` возвращает долю выполнения плана;
- `ask_repeat()` спрашивает про повтор расчёта, возвращает `bool`;
- `print_row`, `print_report`, `print_table` выводят отчёт и таблицу.
